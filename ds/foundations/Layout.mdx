# Layout & spacing

**Grid.** 1440 canvas, 80px gutters, 1280 content. Gutters drop to 40px below 1280 and 20px below 960. The hero is a fixed 1440×627 canvas scaled with `zoom` between 960 and 1440. Everything else is flex / grid.

**Rhythm.** Sections: 140px vertical padding. Title block → content: 48px. Content → section CTA: 48px. Title → subtitle: 24px. Card padding: 32px (24px on rows). Mobile: 96 / 32.

**Radius.** None. Foley UI is square. The only round shapes are icon chips (AI badge, carousel arrows) and pills (TBD badge, review tools).

## Breakpoints
<DimensionTable group="breakpoint" />

| Width | What changes |
|---|---|
| 1440 – 1920 | the whole page scales with the screen (`zoom` = width / 1440, up to ×1.333). Same composition as Figma, bigger type for large monitors |
| > 1920 | scale stays ×1.333, content centred; backgrounds full-bleed, the hero tile grid continues and fades to the edge, the banner photo stays anchored to the column |
| any | every section aligns to one column edge: titles, testimonial track (runs off the right edge), banner copy |
| ≤ 1279 | gutters 40px, nav gap 28px, side columns 380px |
| ≤ 1139 | *Log in* leaves the header, cards tighten, footer badges move into flow |
| ≤ 959 | mobile: info bar and nav hidden, search icon + burger + drawer; every multi-column block stacks |
