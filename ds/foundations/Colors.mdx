# Colors

Semantic tokens only, named like the Figma variables (`text/primary` → `--color-text-primary`). Figma has no primitive scale. Gradient stops that are not semantic colours (`petrol/700`, `petrol/500`) are listed separately.

**Rules**
- Text on light: `text/primary` for content, `text/secondary` for links and supporting copy, `text/tertiary` for meta. Never use `brand/primary` for text on light.
- Dark sections use `--gradient-primary`, never a flat colour.
- Borders: `stroke/primary` around cards and columns, `stroke/secondary` for hairlines inside menus and lists.
- Hover never invents a new hue: it moves one step on the same ramp (bg/tertiary → tertiary-hover → secondary).
